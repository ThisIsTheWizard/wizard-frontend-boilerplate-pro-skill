# Examples

Three reference examples showing what the skill generates for different
framework + library + theme combinations. Each example documents the exact
prompt, interview answers, generated directory structure, key packages, and
notable configuration details.

| Example | Stack | Theme |
|---|---|---|
| [nextjs-shadcn-modern-slate](nextjs-shadcn-modern-slate/README.md) | Next.js 15 + shadcn/ui | Modern Slate — slate + indigo |
| [vue-vuetify-warm-earth](vue-vuetify-warm-earth/README.md) | Vue 3 + Vuetify 3 | Warm Earth — stone + amber |
| [sveltekit-daisy-ocean](sveltekit-daisy-ocean/README.md) | SvelteKit 2 + DaisyUI 4 | Ocean — slate + cyan |

These are reference documents, not runnable projects. To scaffold a real
project, use the skill from your AI agent — see the main [README](../README.md)
for quick-start instructions.
